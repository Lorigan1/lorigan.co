Image Assets
============

Place your images in this folder. Suggested files:

  hero-photo.jpg        — Your photo for the homepage hero section (portrait, ~800x1000px)
  about-photo.jpg       — Your photo for the about section (~800x1000px)

  project-one-thumb.jpg — Thumbnail for project one (~800x500px, 16:10 ratio)
  project-two-thumb.jpg — Thumbnail for project two
  project-three-thumb.jpg — Thumbnail for project three

  project-one-hero.jpg  — Large hero image for project one detail page (~1200x600px)
  project-one-01.jpg    — Additional screenshots for project one
  project-one-02.jpg    — (add as many as needed)

  project-two-hero.jpg  — Same pattern for project two
  project-three-hero.jpg

Tips:
  - Use .jpg for photos, .png for screenshots with text
  - Compress images before adding (tinypng.com or squoosh.app)
  - Keep file sizes under 500KB each for fast loading
